# Dungeons and Data Structures
An interactive exploration into the data structures and algorithms used in TTRPGs and Choose Your Own Adventure Gamebooks. This repository includes a [public site](https://Macavitymadcap.github.io/dungeons-and-data-structures/) hosted with [GitHub Pages](https://pages.github.com/) and all the research and development for the project.

## Running the App

To run the app locally, follow these steps:
1. **Clone the Repository:**
```bash
git clone https://github.com/Macavitymadcap/dungeons-and-data-structures.git
cd dungeons-and-data-structures
```
2. **Install Dependencies:**
```bash
bun install
```

3. **Start the Development Server:**
```bash
bun run dev
```

4. **Access the App:**
Open your web browser and navigate to [http://localhost:8000](http://localhost:8000) to see the app in action.

## Scripts

- `build`: Build the static site.
- `dev`: Start the development server with hot reloading.
- `start`: Start the production server.
- `static:check`: Check for static issues.
- `test`: Run tests.
- `test:static-gamebook`: Run tests specific to the static gamebook.
- `test:watch`: Watch and run tests on file changes.
- `typecheck`: Perform TypeScript type checking.
- `verify`: Verify the app."
